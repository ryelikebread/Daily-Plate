In Safari, tap the Share button, then Add to Home Screen. Open Daily Plate from its icon: that keeps your data safe from Safari's cleanup and lets reminders show as notifications.

Report an issue

Saving puts a ⚠ flag on this food on your device. "Add to GitHub list" opens a pre-filled issue in the Daily Plate repo (you need to be signed in to GitHub and tap Submit there) so the report is kept in a list.
